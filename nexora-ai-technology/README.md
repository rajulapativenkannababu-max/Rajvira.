# Nexora AI — Technology Company

A modern, responsive AI technology company landing page built using HTML and CSS.

## Features
- Dark futuristic hero with product visual
- AI product cards and application areas
- Technology principles and workflow
- Team section and contact call-to-action
- Responsive desktop, tablet and mobile layouts
- Local SVG artwork in `images/`

## Run locally
Open `index.html` in any modern browser. No installation or build step is required.

## Customize
Replace the sample company details, team names, email address and product descriptions with your own content. The SVG artwork can be replaced with real images.

## Deploy
Push the project to a GitHub repository. In **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
